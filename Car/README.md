## Швидка пін-мапа (Pin Map)

| Пін Arduino | Призначення | Примітка |
|-------------|-------------|----------|
| D10 | MOTOR_LEFT_PWM | ШІМ лівого двигуна |
| D8  | MOTOR_LEFT_DIR1 | Напрямок лівого двигуна (1) |
| D9  | MOTOR_LEFT_DIR2 | Напрямок лівого двигуна (2) |
| D5  | MOTOR_RIGHT_PWM | ШІМ правого двигуна |
| D7  | MOTOR_RIGHT_DIR1 | Напрямок правого двигуна (1) |
| D6  | MOTOR_RIGHT_DIR2 | Напрямок правого двигуна (2) |
| D2  | Bluetooth TX модуля → RX Arduino | HC-05/06 |
| D3  | Bluetooth RX модуля ← TX Arduino | Потрібен дільник 5V→3.3V |
| A0  | ІЧ-датчик правий | digitalRead |
| D12 | ІЧ-датчик центральний (опц.) | digitalRead |
| A4  | ІЧ-датчик лівий | digitalRead |
| D13 | Фари (LED_HEADLIGHTS) | Спільно з вбудованим LED, конфлікт з ECHO |
| A1  | Передні габарити |  |
| D11 | Задні габарити + стоп (PWM) | 12,5% габарит, 100% стоп |
| A2  | Поворот лівий | Мигання під час L/G/I |
| A3  | Поворот правий | Мигання під час R/H/J |
| A5  | Індикатор заднього ходу | Вмикається на B/I/J |
| D4  | Бузер (гудок/сигналізація) | Команда Y; також beep у Z |

Увага:

- Піни A6/A7 на класичному Nano — лише аналогові входи (без digitalWrite).

## Опис проєкту

Arduino-керований робот-автомобіль з підтримкою:

- Керування двома двигунами (L298P або аналогічний драйвер)
- Bluetooth дистанційне керування (HC-05/HC-06)
- Опціональні ІЧ-датчики (цифрові)
- Світлодіодна індикація (фари, габарити, стоп-сигнал)

## Характеристики

- **Мікроконтролер:** ATmega328P @ 16MHz
- **Пам'ять:** 2KB RAM, 30KB Flash
- **Швидкість обміну даними:** 9600 baud (Bluetooth і Serial Monitor)

## Схема підключення

### Драйвер двигунів (L298P)

| Пін Arduino | Функція | Опис |
|-------------|---------|------|
| D10 | MOTOR_LEFT_PWM | ШІМ лівого двигуна |
| D8  | MOTOR_LEFT_DIR1 | Напрямок лівого двигуна (1) |
| D9  | MOTOR_LEFT_DIR2 | Напрямок лівого двигуна (2) |
| D5  | MOTOR_RIGHT_PWM | ШІМ правого двигуна |
| D7  | MOTOR_RIGHT_DIR1 | Напрямок правого двигуна (1) |
| D6  | MOTOR_RIGHT_DIR2 | Напрямок правого двигуна (2) |

### Bluetooth модуль (HC-05/HC-06)

| Пін Arduino | Пін модуля | Примітка |
|-------------|------------|----------|
| D2 | TX | Прийом Arduino (RX) |
| D3 | RX | Передача Arduino (TX) — використовуйте дільник напруги 5V→3.3V |
| 5V | VCC | Живлення модуля |
| GND | GND | Земля |

⚠️ **Важливо:** Більшість модулів HC-05/HC-06 працюють на 3.3V логіці. Підключіть резисторний дільник (наприклад, 1kΩ + 2kΩ) між D3 Arduino і RX модуля.

### ІЧ-датчики (опціонально)

*Увімкнено за замовчуванням. Вимкніть за допомогою `-D IR_SENSOR_ENABLED=0` у platformio.ini.*

| Пін Arduino | Датчик |
|-------------|--------|
| A0  | Правий ІЧ-датчик |
| D12 | Центральний ІЧ-датчик (опціонально, `-D IR_SENSOR_CENTER_ENABLED=0`) |
| A4  | Лівий ІЧ-датчик |

**Примітка:** ІЧ-датчики налаштовані як цифрові входи (`digitalRead`). Типові модулі видають LOW (0) при виявленні лінії/об'єкта.

### Освітлення та сигнали

| Пін Arduino | Функція |
|-------------|---------|
| D13 | Фари (LED_HEADLIGHTS) — спільно з вбудованим LED |
| A1  | Передні габарити |
| D11 (PWM) | Задні габарити + стоп-сигнал (ШІМ) |
| D4  | Бузер (гудок/сигналізація) |
| A2  | Поворот лівий |
| A3  | Поворот правий |
| A5  | Індикатор заднього ходу |

Примітки:

- Габарити: передні вмикаються повністю (HIGH), задні — на 12,5% яскравості (ШІМ 32).
- Стоп-сигнал: яскравість 100% (ШІМ 255) під час гальмування протягом 1 секунди.
- Режим парковки: стоп-сигнал світиться постійно, команди руху блокуються.
- Поворотні сигнали автоматично блимать під час команд L/R та діагоналей G/H/I/J. Аварійка — X/x.
- Індикатор заднього ходу (A5) вмикається при русі назад (B, I, J) і вимикається при інших командах.

## Команди Bluetooth

Підключіться до модуля через Bluetooth Serial Terminal (Android/iOS) і надсилайте команди:

| Команда | Дія |
|---------|------|
| `F` | Рух вперед (поточна швидкість) |
| `B` | Рух назад (поточна швидкість) |
| `L` | Поворот ліворуч |
| `R` | Поворот праворуч |
| `G` | Вперед та вліво (діагональ) |
| `H` | Вперед та вправо (діагональ) |
| `I` | Назад та вліво (діагональ) |
| `J` | Назад та вправо (діагональ) |
| `S` | Стоп (зупинка всіх двигунів) |
| `1`–`4` | Встановити швидкість (1=мін, 4=макс) |
| `E` | Перемкнути увімкнення системи (вкл/викл) |
| `Q` | Запит поточної швидкості та стану |
| `U` / `u` | Фари ON / OFF |
| `V` / `v` | Габарити ON / OFF (передні ON, задні 12,5%) |
| `W` / `w` | Режим парковки ON / OFF |
| `X` / `x` | Аварійка ON / OFF (мигання обох поворотів) |
| `Z` | Перемкнути cигналізаці. (мигання + періодичний біп) |
| `Y` | Гудок: коротка мелодія один раз |

**Приклад:**

```text
4      # Встановити середню швидкість
V      # Увімкнути габарити (передні ON, задні 12,5%)
U      # Фари ON
G      # Рух вперед-ліворуч (діагональ)
S      # Стоп — стоп-сигнал 1 сек на 100%
W      # Режим парковки ON — мотори заблоковано, стоп-сигнал світиться
w      # Режим парковки OFF
u      # Фари OFF
v      # Габарити OFF
```

## Налаштування компіляції

Змініть `platformio.ini`, щоб увімкнути/вимкнути датчики:

```ini
[env:nanoatmega328new]
platform = atmelavr
board = nanoatmega328new
framework = arduino
build_flags = 
  -D IR_SENSOR_ENABLED=1            ; 1=увімкнено, 0=вимкнено
  -D IR_SENSOR_CENTER_ENABLED=1     ; 1=центральний ІЧ увімкнено, 0=вимкнено
```

**За замовчуванням:** Усі датчики вимкнено.

## Основні функції

### Керування двигунами

- `motorStop()` — зупинити всі двигуни
- `motorForward(speed)` — рух вперед
- `motorBackward(speed)` — рух назад
- `motorTurnLeft(speed)` — поворот ліворуч
- `motorTurnRight(speed)` — поворот праворуч
- `setMotorSpeed(leftSpeed, rightSpeed)` — індивідуальне керування

### Датчики

- `readUltrasonicDistance()` — відстань у см (0 якщо вимкнено)
- `readIRSensor(pin)` — цифрове значення 0/1

### Bluetooth

- `handleBluetoothInput()` — обробка вхідних команд (неблокуюча)
- `processBTCommand(char)` — виконання команди

### Освітлення

- `setHeadlights(bool)` — вмикає/вимикає фари (D13)
- `setParkingLights(bool)` — габарити: передні (A1) ON/OFF, задні (D11 PWM) 50%/0%
- `setParkingMode(bool)` — режим парковки ON/OFF (блокує рух, задні на 100%)
- `activateBrakeLight()` / `updateBrakeLight()` — стоп-сигнал на 1 секунду при гальмуванні

### Утиліти

- `blinkLED(pin, times, delayMs)` — мигання світлодіодом

## Усунення несправностей

**Bluetooth не підключається:**

- Перевірте пароль (зазвичай `1234` або `0000`)
- Переконайтеся, що модуль живиться 5V
- Перевірте швидкість обміну даними (9600 за замовчуванням)

**Двигуни не обертаються:**

- Перевірте підключення драйвера
- Переконайтеся, що `systemEnabled = true` (надішліть `E` для перемикання)
- Перевірте живлення двигунів (окреме від Arduino)

**Датчики не читаються:**

- Перевірте прапорці компіляції в `platformio.ini`
- Переконайтеся в правильності підключення VCC/GND
- Перегляньте Serial Monitor для виводу налагодження
